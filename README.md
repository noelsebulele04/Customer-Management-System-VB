# Customer Management System (VB.NET)

A Windows Desktop application built in Visual Basic .NET to handle customer record management, text file storage, and data searching.

## Features
* **Sequential File I/O:** Reads and writes structured customer data from `customers.txt` using `StreamReader` and `StreamWriter`.
* **In-Memory Storage:** Uses custom VB `Structure` definitions and arrays to manage record state during runtime.
* **Input & Field Validation:** Includes user-defined functions to validate email syntax and integer customer IDs.
* **Search Functionality:** Real-time search filtering through customer array records by name.

## Tech Stack
* **Language:** Visual Basic .NET (VB.NET)
* **UI Framework:** Windows Forms (WinForms)
* **IDE:** Microsoft Visual Studio

## Setup & Running
1. Clone the repository or download the ZIP file.
2. Open `TrendWear Clothing Customer Manager.sln` in Visual Studio.
3. Build and run the project by pressing **F5**.
